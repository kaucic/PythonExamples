# Reinforcement Learning Project

This project contains resources and code examples for exploring reinforcement learning concepts using Python. It includes environment setup instructions and Jupyter notebooks for hands-on experimentation.

## Project Structure

- `environment.yaml` — Conda environment specification for all required dependencies.
- `minimal_model_of_farkle.ipynb` — Jupyter notebook exploring a minimal model of the Farkle game using reinforcement learning techniques.
- `tic-tac-toe_reinforcement_learning.ipynb` — Jupyter notebook implementing reinforcement learning for the game of Tic-Tac-Toe.

## Getting Started

1. Create the Conda environment:
   ```sh
   conda env create -f environment.yaml
   ```
2. Activate the environment:
   ```sh
   conda activate reinforcement-learning
   ```
3. Launch Jupyter Notebook:
   ```sh
   jupyter notebook
   ```
4. Open and run the notebooks to explore the examples.

## Requirements
- Python 3.12
- Conda
- Jupyter
- numpy, pandas, matplotlib

All dependencies are listed in `environment.yaml`.
